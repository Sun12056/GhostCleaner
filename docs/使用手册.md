# WinCleaner 使用手册

> 适用：Windows 10 / 11 ｜ 运行方式：管理员权限 ｜ 默认行为：**只检测，不删除**

---

## 1. 这个工具解决什么问题

你把 C 盘重置（或重装系统）之后，D / E / F 盘上以前安装的软件**目录还在**，但 Windows 注册表里已经**没有**它们的卸载项和安装信息了。于是：

- 「应用和功能」里看不到它们 → 无法卸载；
- 控制面板里也没有 → 无法清理；
- 只能人肉翻目录，不敢乱删（怕删了还有用的东西）。

WinCleaner 做的事：**把这些"看起来像软件安装目录、但系统里已经找不到任何引用"的目录找出来**，给出判定依据和风险等级，让你确认后再安全地处理掉。

---

## 2. 安全原则（请先记住这 5 条）

1. **扫描不会删除任何东西**，扫描阶段零风险，随便扫。
2. **结果默认全部不勾选**。必须你自己勾选，才会处理。
3. **默认动作是"移到隔离区"**，不是删除；隔离区里的东西**可以一键还原**。
4. **永久删除**需要勾选后手动选择，并且**输入确认文字**二次确认。
5. **系统目录、用户数据目录会直接标成高风险并禁止删除**（Windows / System32 / Users / AppData / ProgramData / Recovery / Boot / EFI / 驱动目录等）。

## 3. 安装与启动

### 3.1 启动方式

| 方式 | 操作 |
|---|---|
| 快捷方式 | 双击 `D:\文档\GitHub\GhostCleaner\WinCleaner.lnk` |
| 批处理 | 双击 `D:\文档\GitHub\GhostCleaner\Run-WinCleaner.bat` |
| 直接运行 | 双击 `D:\文档\GitHub\GhostCleaner\app\WinCleaner.App.exe` |

程序是**自包含单文件**发布（约 68 MB），**不需要安装 .NET 运行时**，所有文件都在 D 盘，不往 C 盘写任何东西。

### 3.2 第一次启动会看到什么

- **UAC 弹窗**：「是否允许此应用对你的设备进行更改？」→ 点 **是**。
  程序需要管理员权限才能完整读取注册表 Uninstall 项、Windows 服务、计划任务等信息。
- **SmartScreen 提示**（未签名程序）：若出现「Windows 已保护你的电脑」→ 点 **更多信息** → **仍要运行**。
- 主窗口左上角会显示权限状态：
  - 「已以管理员身份运行」→ 正常；
  - 「未以管理员身份运行，部分操作可能失败」→ 建议关闭后右键以管理员身份启动。

## 5. 孤儿软件扫描：完整使用流程

### 第 1 步：选择扫描范围（孤儿软件扫描页）

- 勾选要扫的盘符（D、E、F …）；
- 也可以点「添加目录」指定自定义目录（例如 `D:\我的软件`）。

程序会自动把每个盘下的这些常见安装位置纳入扫描：

```
盘符根目录
<盘>:\Program Files
<盘>:\Program Files (x86)
<盘>:\Software
<盘>:\Apps
<盘>:\Games
<盘>:\Tools
<盘>:\GreenSoft
用户自定义目录
```

### 第 2 步：点击「开始扫描」

- 扫描是**异步**的，界面不会卡死，可随时点「停止扫描」；
- 大目录 + 机械硬盘可能要几分钟，耐心等进度条走完。

### 第 3 步：看结果表格

每一条结果包含：

| 列 | 说明 |
|---|---|
| 路径 | 疑似软件安装目录的完整路径 |
| 软件名 | 从目录名 / exe 版本信息推测的名字 |
| 版本 / 厂商 | 从主 exe 的 PE 版本资源读取（读不到则为空） |
| 大小 | 目录总大小 |
| 文件数 | 目录下文件总数 |
| 最后修改 | 最后一次修改时间 |
| 主程序 | 找到的主要 exe |
| 有卸载器 | 是否含 `uninstall.exe` / `unins000.exe` 等 |
| **疑似残留度** | 0–100%：程序有多大把握认为它是残留（**不等于可以删除**） |
| **风险** | 低 / 中 / 高：清理它出问题时的代价 |
| **建议** | 建议保留 / 建议人工确认 / 建议人工确认后隔离 / 高风险必须人工复核 |
| **性质** | 游戏 / 开发项目 / 绿色软件 / 用户数据 / — |
| 判定依据 | 逐条列出正向证据与保护性证据（选中一行后在下方可展开查看） |
| 勾选 | 是否纳入处理（**默认不勾**） |

### 第 4 步：判断依据是怎么来的

> **重要**：**「没有找到系统引用」本身不等于「它是软件残留」。**
> 绿色软件、游戏、开发项目、外部磁盘上的软件天然就可能没有卸载注册表项。
> 因此程序输出的是**证据 + 置信度 + 风险 + 建议**，而不是"删不删"的结论。

程序会先建立一份「系统当前仍在使用哪些路径」的索引，来源包括：

- 注册表 Uninstall 项（HKLM / HKCU 的 32 位与 64 位四个位置）
- 开始菜单快捷方式（含 `.lnk` 解析出的目标路径）
- 桌面快捷方式
- Windows 服务（可执行文件路径）
- 计划任务
- 当前正在运行的进程
- Microsoft Store / AppX 包
- 文件关联、右键菜单、启动项

**只有当目录"长得像被安装出来的软件"，且上面这些来源在"扫描成功"的前提下都没有命中时**，
缺少关联才会作为一条**正向证据**参与打分；它永远只是证据之一，不是结论。

同时，程序会主动识别并保护这些"天然没有系统关联"的目录：

- **绿色 / Portable 软件**（免安装、配置与 exe 同目录、无安装卸载程序）
- **游戏目录**（Steam / Epic / Ubisoft / GOG … 以及 `steam_api*.dll`、`UnityPlayer.dll` 等引擎文件）
- **开发项目 / 工具链**（`.git`、`node_modules`、`package.json`、`pom.xml` …）
- **用户数据**（`save` / `saves` / `profile` / `userdata` / `backup` / `documents` …）
- **系统安装目录**（`Program Files` / `Program Files (x86)` / `Windows`）

**如果某个来源扫描失败，程序绝不会把它当成"没有引用"**，而是给出警告并压低置信度上限。

### 第 5 步：疑似残留度 / 风险 / 建议怎么看

| 置信度 | 含义 |
|---|---|
| 0–39% 普通 | 没有足够的残留特征 |
| 40–69% 可疑 | 需要人工确认 |
| 70–89% 高概率残留 | 需要人工确认 |
| 90–100% 非常高概率残留 | 仍需人工确认后才处理 |

| 风险等级 | 含义 | 建议 |
|---|---|---|
| **低** | 非系统盘、像软件目录、有卸载器、长期未修改、无进程占用 | 人工确认后可隔离 |
| **中** | 目录里有用户数据/配置/存档，或近期仍有修改，或缺少卸载程序 | **先打开目录人工确认** |
| **高** | 路径命中 `Windows` / `System32` / `Users` / `AppData` / `ProgramData` / `Recovery` / `Boot` / `EFI` / 驱动目录等关键位置，或关联检查不完整 | **不允许删除**，只显示供参考 |

> 分级规则是**保守**的：宁可漏掉，也不误删。
> 扫描器**永远不会输出"删除"**，只输出建议；真正的处理必须由你勾选后执行。

### 第 6 步：处理（三种方式，都要人工勾选）

1. **移到隔离区（推荐、默认）**
   目录被移动（不是复制）到隔离区，原位置消失；隔离区保留 7–30 天（设置里可调），期间**随时可还原**。
2. **删除到回收站**
   走 Windows 回收站，可以从回收站还原（超大文件可能跳过回收站，程序会提示）。
3. **强制永久删除**
   **必须输入确认文字**才能执行，不可恢复，请谨慎。

处理前，程序会按设置尝试创建**系统还原点**（设置里可开关）。

---

## 6. 隔离区

- 默认位置：自动选择剩余空间最大的非系统盘（例如 `D:\CleanerQuarantine`），可在设置里改。
- 每个被隔离项都有一份 `manifest.json`，记录原始路径、时间、大小，用于还原。
- 支持：**还原到原位置**、**彻底删除**、**清空隔离区**。
- 到期（保留天数）后可在隔离区页面手动清理。

---

## 7. 白名单 / 保留关键词

在「设置」页配置，**命中即不参与删除**：

- **排除路径（白名单）**：例如 `D:\Games\SteamLibrary`、某个工作目录。
- **保留关键词**：目录路径或名字里包含这些词的，一律跳过，例如：
  `SteamLibrary`、`Epic`、`工作`、`项目`、`Backup`、`存档`、`Save`。

建议第一次扫描前先把游戏库、工作目录加进去。

---

## 8. 注册表清理（启动项 / 注册表 页）

可扫描并清理：

- 无效的卸载项（`Uninstall` 下指向不存在路径的条目）
- 无效的文件关联
- 无效的服务项
- 无效的启动项

**所有注册表修改前都会自动备份**，备份目录在程序数据目录下的 `Backups`。注册表操作请逐条确认，不要一次全选。

---

## 9. 日志与报告导出

- 日志按天存储为 JSONL：`数据目录\Logs\wincleaner-YYYY-MM-DD.jsonl`；
- 每条记录包含：时间、类别、动作、路径、大小、结果、说明；
- 扫描结果和清理结果都可导出为 **JSON / CSV**，按钮在对应页面右上角。

## 10. 设置项一览

| 设置 | 说明 | 默认 |
|---|---|---|
| 隔离区路径 | 被隔离文件的存放位置 | 空间最大的非系统盘 |
| 保留天数 | 隔离区保留时长 | 30 天（可调 7–30） |
| 白名单路径 | 永不处理的目录 | 空 |
| 保留关键词 | 命中即跳过 | 空 |
| 创建系统还原点 | 处理前尝试创建还原点 | 开 |

## 12. 常见问题

**Q1：双击没反应 / 打不开？**
- 先看有没有 UAC 弹窗（可能在其他窗口后面）；
- 右键 → 以管理员身份运行；
- 若提示缺少 .NET：请使用 `app\WinCleaner.App.exe`（自包含版，不需要 .NET）。

**Q2：扫描很久没结束？**
- 机械硬盘扫大目录本来就慢；看进度条是否还在动；
- 可以缩小范围，只勾一个盘或指定目录。

**Q3：会不会误删正在用的软件？**
- 正在运行的进程路径会被识别为「仍有关联」，不会被判为残留，并直接标记为高风险必须人工复核；
- 有服务、计划任务、快捷方式引用的同样不会被判为残留；
- 中风险项请先「打开目录」人工看一眼。

**Q4：扫出来是我还在用的绿色软件 / 游戏 / 开发项目怎么办？**
- v0.1 会主动识别绿色软件、游戏目录、开发项目与用户数据目录，
  这些目录置信度会被大幅压低，并且**不会**被自动推荐清理；
- 如果仍然不想看到它：把路径加到**白名单**，或者把软件名加到**保留关键词**，下次扫描会自动跳过。

**Q4.1：为什么有的条目写着「扫描结果可能不完整」？**
- 说明某个关联来源（例如注册表卸载项）这次没能完成检查；
- 这种情况下程序**不会**认为「没有引用」，只会压低置信度并提示你人工确认。

**Q5：隔离区把东西移走后软件打不开了？**
- 去隔离区点「还原」，会还原到**原始路径**。
