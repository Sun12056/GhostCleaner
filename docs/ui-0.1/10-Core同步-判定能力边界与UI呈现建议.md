## 一、先给结论

**Core 目前不能可靠判定"这是残留"。** 请不要把置信度当作结论呈现给用户，
把它当作**待用户确认的证据强度**。

你那条反向发现（要修采集器上报而不是闸门）已经落地并验证，
顺着它往下查之后，问题比我们原先说的更大 —— 不只是"未提权时不准"，
而是**即使提权、采集完整，判定本身也不准**。

## 二、数据

### 2.1 判定准确率

| 指标 | 实测 | 门槛 | 判定 |
|---|---|---|---|
| `Precision`（判为残留里真残留的比例） | **0.333** | ≥0.90 | ❌ |
| `Recall`（真残留里被找出来的比例） | **0.333** | ≥0.60 | ❌ |
| `AUC`（排序区分能力，0.5=随机） | **0.648** | ≥0.8 才可用 | ❌ |

**置信度最高的正类和负类都是 96 分 —— 完全重叠。**

### 2.2 具体误报（真值都是"在用"）

| 目录 | Core 置信 | 用户真值 |
|---|---|---|
| `D:\wangyiyunyinyue` | **96（非常高概率残留）** | 在用 |
| `D:\Weixin` | **81（高概率残留）** | 在用 |
| `D:\IROK Software` | 58 | 在用 |
| `D:\Microsoft VS Code` | 46 | 在用 |

### 2.3 根因：重装场景

用户机器重装过系统，D 盘留下的正是**正规安装的软件目录**。
重装后注册表登记全部丢失 → `MissingUninstallEntry(+20)` 等"缺失关联"证据**在
所有目录上都成立**，失去区分度。

> 「完整软件特征 + 缺失系统关联」在本机上等于**「重装后仍在用的软件」**，
> 而 Core 把它当成残留。

### 2.4 已尝试修、但不够

- 改动 3（近期活动文件数 −25）：微信 100 → 81，**只降了等级，仍是误报**
- 调权重测算：最好只能把 Precision 从 0.333 提到 **0.5**，且 Recall 不改善
- 新信号调研（AppData / UserAssist / Recent）：全部不可行，其中一个 **AUC 0.327（反向）**

## 三、对 UI 的具体建议（按优先级）

### P0-1：不要呈现"这是残留"的确定性措辞

现状风险：96 分会渲染成「非常高概率残留」，但它实际是天天在用的网易云音乐。

建议改为**描述"没检测到什么"，而不是"它是什么"**：

| 现在 | 建议 |
|---|---|
| 非常高概率残留 | **未检测到使用迹象**（置信度 96） |
| 高概率残留 | 使用迹象很少（置信度 81） |
| 可疑 | 部分关联缺失（置信度 58） |

同时在条目上**始终**给出可核验的出口：

- `打开所在目录`
- `在文件资源管理器中显示`
- 若有自带卸载器 → `使用其自带卸载器卸载`（见 P0-2）

### P0-2：展示 Core 新增的两类 warning

Core 现在会产出这些 `warnings`，麻烦在条目详情里显示：

1. `该目录自带卸载程序，建议优先使用其自带卸载器卸载；直接删除目录会残留注册表项与系统关联`
   → **建议给它一个"运行自带卸载器"按钮**，这是比删除安全得多的路径
2. `未能完成【运行中的进程】检查，无法确认该目录是否正在被使用`（未提权时，47 条中 41 条会带上）
   → 这是"不确定"信号，不是"可清理"信号，语气要体现

### P0-3：隔离 / 删除的确认闸门请保留，并考虑加强

**Core 目前从不输出 `Quarantine`（0/47）。** 也就是说，用户手动点"移入隔离区"
这个动作，是**完全绕过 Core 判定**的 —— 确认闸门是最后一道防线，不是多余步骤。

基于上面的准确率数据，我的意见是：**你原来的分级方案是对的，我赞成，不建议放宽**。
如果还要加强，优先级是：

1. 批量操作前，单独提示"本次选中的 N 项中，有 M 项近 90 天内有文件活动"
2. 对置信度 ≥90 的条目**反而要更谨慎**（本轮 96 分那条就是误报）

### P1：置信度条不要单独作为"危险程度"配色依据

96 分的配色如果是红色，会直接诱导用户删除天天在用的软件。
建议配色跟**风险等级（RiskLevel）**走，或干脆用中性色 + 明确的"待确认"标签。

### P1：提权引导仍然重要，但理由要更新

未提权时更差（进程采集不完整），这条没变。但现在要补一句：
**即使提权，判定依然不可靠** —— 所以不能让用户以为"提权后就准了"。
