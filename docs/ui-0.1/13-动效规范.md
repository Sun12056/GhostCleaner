# 动效规范 v0.1

## 1. 原则

1. **动效服务于理解，不服务于炫技。** GhostCleaner 是工具，动效必须可被忽略。
2. **只动画 `opacity` 与 `transform`。** 禁止动画 `width` / `height` / `margin` / `padding`（折叠面板高度除外）。
3. **页面切换无动画。** 桌面应用导航应该即时。
4. **尊重系统设置。** `prefers-reduced-motion` / WPF `SystemParameters.ClientAreaAnimation == false` 时，全部时长归 0。

## 2. 时长与曲线

| Token | 值 | 用于 |
|---|---|---|
| `dur.instant` | 0ms | 禁用态切换、输入框错误态 |
| `dur.fast` | 120ms | 颜色 / 背景 / 边框过渡；图标旋转 |
| `dur.normal` | 200ms | 面板展开、抽屉滑入、Toast 进出、列表项插入 |
| `dur.slow` | 320ms | 对话框出现 |
| `ease.standard` | `cubic-bezier(.2, 0, 0, 1)` | 默认（Fluent standard） |
| `ease.decelerate` | `cubic-bezier(0, 0, .2, 1)` | 进入（元素出现在屏幕上） |
| `ease.accelerate` | `cubic-bezier(.4, 0, 1, 1)` | 退出 |
| `ease.linear` | `linear` | 进度条、不确定进度、骨架呼吸 |

## 3. 逐组件动效表

| 元素 | 触发 | 动画 | 时长 | 曲线 |
|---|---|---|---|---|
| Button | Hover / Pressed | `background-color` | 120ms | standard |
| IconButton | Hover | `background-color` + `color` | 120ms | standard |
| NavigationItem | Hover / Active | `background-color` + `color` + 左指示条 `opacity` | 120ms | standard |
| CheckBox | Checked | `background-color` + 勾 `opacity 0→1` | 120ms | standard |
| Switch | Toggle | 滑块 `translateX(0→16px)` | 120ms | standard |
| Expander | 展开 / 折叠 | 箭头 `rotate(0→90deg)` + 内容高度 | 200ms | standard |
| Segmented | 选中迁移 | `background-color`（**不做滑块位移**） | 120ms | standard |
| Input | Focus | `border-color` + 焦点环出现 | 120ms | standard |
| Table 行 | Hover | `background-color` | 120ms | standard |
| ResultItem | 插入 | `opacity 0→1` | 200ms | decelerate |
| ConfidenceBar | 数值变化 | `width` | 200ms | standard |
| Progress（确定） | 进度变化 | `width` | 120ms | linear |
| Progress（不确定） | 常驻 | 30% 宽滑块 `translateX(-100% → 333%)` | 1.4s | linear 无限 |
| 扫描进度环 | 进度变化 | `stroke-dashoffset` | 120ms | linear |
| Dialog | 出现 | `opacity 0→1` + `scale(.96→1)` | 320ms | decelerate |

| 页面切换 | — | 内容 `opacity 0→1` | 120ms | decelerate |
| 骨架屏 | 常驻 | `opacity 1→.55→1` | 1.4s | linear 无限 |

## 4. 明确禁止的动效

| ❌ | 原因 |
|---|---|
| 数字滚动计数（counting up） | 制造虚假的"实时"感；残留在扫描结果里尤其误导 |
| 弹跳 / 回弹（overshoot） | 工具不需要俏皮 |
| 卡片悬浮放大 | Web 感 |
| 页面滑动转场 | 桌面应用不需要 |
| 扫描完成时的撒花 / 粒子 | 与 Calm 定位冲突 |
| 进度条到 100% 时的闪光 | 同上 |
| 图标连续旋转超过 1 圈（Loading 除外） | 干扰 |
| 渐变位移 / 流光边框 | 设计红线 |

## 5. 加载与进度

| 场景 | 处理 |
|---|---|
| 进度已知 | 确定进度条 / 环，`ease.linear`，**禁止缓动**（缓动会让进度看起来不准） |
| 进度未知 | 不确定进度条（1.4s linear 循环） |
| 短操作（< 300ms） | **不显示 Loading**，直接完成（避免闪烁） |
| 长操作（> 2s） | 显示进度文案（当前路径 / 当前步骤），不只是转圈 |

## 6. WPF 实现映射

| CSS / 概念 | WPF |
|---|---|
| `transition` | `VisualStateManager` 的 `VisualTransition`（`GeneratedDuration`）或 `Storyboard` |
| `cubic-bezier(.2,0,0,1)` | `SplineEaseInOut` 的 `KeySpline="0.2,0 0,1"` |
| `@keyframes` 无限循环 | `Storyboard` + `RepeatBehavior="Forever"` |
| `prefers-reduced-motion` | `SystemParameters.ClientAreaAnimation` / `SystemParameters.PowerLineStatus`… 实际用 `SystemParameters.ClientAreaAnimation` |
| `transform: translateX` | `TranslateTransform` on `RenderTransform`（**不是** `LayoutTransform`） |
| 骨架呼吸 | `DoubleAnimation` on `Opacity`，`AutoReverse="True"`，`RepeatBehavior="Forever"` |
