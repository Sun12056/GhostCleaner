# 页面设计规格 v0.1

> 可运行原型：`prototype/index.html`（`#/路由`）。
> 尺寸单位 px @96dpi。所有间距/颜色/字号均引用 `07-DesignTokens.md` 的 token。

---

## 0. 全局骨架

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 32px（Logo + 应用名 + 最小化/最大化/关闭）               │
├────────────┬─────────────────────────────────────────────────┤
│ 侧栏 232px │  内容区（padding 24/32，最大宽 1400）             │
│            │                                                  │
│ 品牌       │  ┌ 页面标题区（h1 + 说明 + 右上操作）            │
│ 7 个导航   │  ├ 内容                                          │
│            │  └ （结果页/隔离区）底部操作栏 64px               │
│ ─────────  │                                                  │
│ 版本/权限  │                                                  │
└────────────┴─────────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 标题栏 | 高 32，bg `bg.sidebar`，下边线 `border.subtle`。**不自定义绘制** —— UI 0.2 用系统标题栏 + `WindowChrome` 扩展 |
| 侧栏 | 宽 232，bg `bg.sidebar`，右边线 `border.subtle`；品牌区高 56；底部状态区显示版本与管理员状态 |

| 页面标题 | `h1` 20/28/600 + 说明 `body-sm` `text.secondary`（最大宽 720）；右上角放本页次要操作 |

## 1. 概览 Dashboard

**主任务**：回答「GhostCleaner 现在能为我做什么」。

### 结构

| # | 区块 | 规格 |
|---|---|---|
| 1 | 权限提示条 | `banner-warning`（仅非管理员时显示）。**不阻断**，可关闭当天提醒 |
| 2 | Hero | `bg.surface` + 边框，padding 32。左：标题 `title` 24/32/600「发现 Windows 忘记的软件残留。」+ 说明；右：`开始扫描`（Primary lg 40px） |
| 3 | 度量组 | 4 个 `MetricTile`，grid `repeat(4, 1fr)` gap 16 |
| 4 | 最近一次扫描 | 卡片：范围徽章 + 摘要文本 + 「查看结果」按钮 |
| 5 | 需要你看一眼 | 卡片：最多 3 条 `conf ≥ 70 且存在保护信号/警告` 的条目，每条显示 名称 / 路径 / 置信度条 / 风险徽章 / 「查看」 |

### 度量项定义

| 项 | 取值 | 口径 |
|---|---|---|
| 上次扫描 | `2 天前` | 相对时间；副行 `2026-10-05 14:22 · 耗时 42.6 秒`。无记录时显示 `从未扫描` |
| 疑似残留 | `7 项` | 上次扫描未排除条目数；副行 `高概率 3 · 需要复核 4` |
| 预计可释放 | `8.6 GB` | `sum(SizeBytes) where !IsExcluded`。**标签必须是「预计可释放」**，不能写「可释放空间」（避免承诺） |
| 隔离区 | `3 项` | 副行 `保留 15 天 · 最早 12 天后到期` |

### 空态（首次启动）

Hero 保持不变，度量区替换为：

```
[gc-scan 48px]
还没有扫描过
开始第一次扫描，看看 Windows 忘记了什么。
[开始扫描]
```

「最近一次扫描」「需要你看一眼」两张卡片隐藏。

## 2. 残留扫描 Scan

**主任务**：确定扫描范围并启动。

| # | 区块 | 规格 |
|---|---|---|
| 1 | 扫描范围卡片 | 标题 + 已选根路径计数 |
| 1a | 磁盘 | `drive-grid` `repeat(auto-fill, minmax(220px,1fr))` gap 12；每张卡片含 图标 + 盘符 + 系统盘徽章 + `可用 X / 共 Y`（tabular）。选中态：边框 `accent.500` + 底 `accent.50` |
| 1b | 自定义目录 | 路径列表（mono 12）+ 移除 IconButton；下方 路径输入框 +「选择文件夹」+「添加常见安装目录」 |
| 1c | 卡片底栏 | 左：口径说明（caption）；右：`开始扫描`（Primary） |
| 2 | 扫描选项（折叠） | `expander`（默认关闭）：最大扫描层级 / 包含隐藏目录 / 软件判定阈值 / 跳过符号链接 |

### 交互

- 系统盘 C: 默认**不勾选**（现状 `DriveOption.IsSelected = !IsSystemDrive` 已如此）。
- 未选任何根路径点「开始扫描」→ Toast 警告，按钮不进入 Loading。
- 非管理员点「开始扫描」→ **不弹阻断对话框**，改为：扫描页顶部出现 `banner-warning`，扫描完成后再次提示。
- 点击「开始扫描」→ 进入 **扫描中** 页。

## 3. 扫描中 Scanning

**主任务**：让用户知道现在在做什么、进展如何、随时可以停。

| # | 元素 | 规格 |
|---|---|---|
| 1 | 阶段步骤条 | 4 步：`建立关联索引 → 枚举候选目录 → 逐个度量 → 分析判定`。已完成 ✔、当前 ●、未开始 ○ |
| 2 | 进度环 | **直径 88px**（V8 禁止更大），轨道 6px `n.200`，填充 `accent.500`，中心百分比 20/600 tabular |
| 3 | 当前阶段 + 路径 | 阶段名 `h2`；路径 `font.mono` 12，**单行截断**（`direction:rtl` 保留尾部） |
| 4 | 时间 | `已用 00:27 · 预计剩余 00:16`（tabular） |
| 5 | 统计组 | 4 项居中：已检查目录 / 发现候选 / 疑似残留 / 已扫描体积。数字 `title` 24/32/600 tabular |
| 6 | 操作 | `暂停`（Secondary）+ `取消`（Secondary）。**不使用 Danger 色**（取消不是危险操作） |
| 7 | 实时候选列表 | 最大高 200px，滚动；每行 图标 + 路径 + 大小 + 置信度徽章 |

### 暂停态

- 进度环填充改为 `n.400`（失去强调），中心保持百分比。
- 阶段文案 → `已暂停`。
- 「暂停」按钮变 `继续`（图标 `gc-play`）。
- 统计数字冻结。

### 降级方案

若 Core 未提供 `UDR-01`（暂停）与 `UDR-05`（阶段），UI 0.2 先实现：单阶段「正在扫描」+ 只有「取消」。步骤条与暂停按钮隐藏。

## 4. 扫描完成 Scan Complete

**主任务**：用最少的信息告诉用户"扫完了，结果是什么"，并引导到结果页。

| # | 元素 | 规格 |
|---|---|---|
| 1 | 成功标记 | `gc-circle-check` 48px，`success.default` |
| 2 | 标题 | `title`「扫描完成」+ 说明「已检查 18,492 个目录，耗时 42.6 秒。默认未勾选任何条目。」 |
| 3 | 主数字 | `metric-lg` 36/40/600：`发现 12 个疑似残留` |
| 4 | 统计组 | 已检查目录 / **高概率残留** / **需要人工确认** / 预计可释放 |
| 5 | 警告条 | 仅当 `ScanWarnings.Count > 0` 时显示（如关联来源未完成检查） |
| 6 | 操作 | `查看扫描结果`（Primary lg）/ `重新扫描`（Secondary）/ `导出报告`（Subtle） |

> **「高概率残留」与「需要人工确认」必须是两个独立数字**，绝不能合并展示为「发现 12 个问题」。

## 5. 扫描结果 Results ★ 核心页

**主任务**：快速理解 + 快速筛选 + 安全决策。

### 布局

```
┌──────────────────────────────────┬───────────────┐
│ 页面标题 + 导出 / 重新扫描        │               │
│ 工具栏：筛选分段 + 搜索 + 排序    │  详情面板      │
│ ─────────────────────────────── │  420px         │
│ 结果列表（滚动）                  │  sticky top 0 │
│  · 结果项 72px                    │               │
│  · 结果项                         │               │
├──────────────────────────────────┤               │
│ 底部操作栏 64px（有勾选时）       │               │
└──────────────────────────────────┴───────────────┘
```

| 区域 | 规格 |
|---|---|
| 左列 | `minmax(0, 1fr)` |
| 右列 | **420px**；窗口 < 1180 → 覆盖式抽屉（滑入 + 遮罩） |
| gap | 16 |

### 工具栏

`全部 (9) | 高可信度 (6) | 需要复核 (4) | 受保护 (2)`（Segmented，带计数）
右侧：搜索框 200px + 排序下拉（按疑似残留度 / 按大小 / 按路径 / 按清理风险）。

### 结果项（ResultItem）

```
☐  ExampleApp                            [中] [已保护]
   D:\Program Files\ExampleApp                 1.42 GB
   ▓▓▓▓▓▓▓▓▓░░ 92%   未发现卸载项 · 未发现服务 · 731 天未改
```

- 高 72，padding 12/16，行分隔线 1px `border.subtle`（**逐项不用卡片**）。
- `Selected`（正在看）= `bg.active` + 左侧 3px `accent.500`。
- `Checked`（要处理）= 复选框变 `accent.500` 实心。**两者视觉独立**。
- 受保护 / 已排除：复选框 `disabled`，名称降为 `text.secondary`，加状态徽章。
- 依据摘要最多 3 条，`·` 分隔，超出 `+N`。

### 详情面板

| # | 区块 | 内容 |
|---|---|---|
| 1 | 头部 | 名称 + 风险徽章 + 状态徽章；路径（mono，单行截断）+ 复制 + 打开文件夹 |
| 2 | 判定结论 | 双栏：`疑似残留度`（大号 ConfidenceBar + 等级文案） / `清理风险`（徽章 + `ProtectionReason`） |
| 3 | 推荐操作 | banner：`推荐操作：{RecommendationText}` + 「不会自动执行」 |
| 4 | 警告 | 仅 `Warnings.Count > 0` |
| 5 | 检测依据 | 标题 `检测依据 · 支持「是残留」(N)`；`EvidenceItem` 列表（正向） |
| 6 | 保护信号 | 标题 `保护信号 · 支持「保留」(N)`；`EvidenceItem` 列表（负向） |
| 7 | 文件信息 | `kv` 两列：大小 / 文件数 / 目录数 / 最后修改 / 版本 / 厂商 / 目录分类 |
| 8 | 系统关联 | 列出所有 `未发现 X` 类证据 |
| 9 | 底部操作 | `移入隔离区`（Primary）/ `打开文件夹` / `运行卸载程序`（无卸载器时 disabled）/ `加入白名单` |

> **正向与负向证据必须分区**（`OrphanItem.PositiveEvidence` / `NegativeEvidence`）。禁止混排。
> 未选中任何条目时，详情面板显示 EmptyState。

### 底部操作栏

```
已选 3 项 · 共 5.9 GB        [全部取消] [仅选低风险]  [移入隔离区] [永久删除]
```

- 高 64，`bg.surface` + 上边线 + `elevation.1`，sticky bottom。
- `已选 0` 时**隐藏整条**（不是显示禁用状态）。
- 主动作只有 `移入隔离区`（Primary）；`永久删除` 用 Danger-Subtle（**不用实心红**）。
- 提供「仅选低风险」而非「全选推荐项」—— 辅助必须有明确边界。

### 空态

| 场景 | 图标 | 文案 |
|---|---|---|
| 从未扫描 | `gc-scan` | 还没有扫描过。开始第一次扫描，看看 Windows 忘记了什么。 |
| 筛选后为空 | `gc-filter` | 当前筛选条件下没有条目。试试切换筛选或清空搜索。 |
| 全部已处理 | `gc-circle-check` | 本次扫描结果已全部处理完毕。 |

## 6. 隔离区 Quarantine

**主任务**：恢复或永久清除。

| # | 区块 | 规格 |
|---|---|---|
| 1 | 度量组 | 隔离条目 / 占用空间 / 保留天数 / 最早到期 |
| 2 | 表格 | 复选框 / 名称 / 原始路径（mono）/ 大小 / 隔离时间 / 剩余天数 / 状态 / 打开位置 |
| 3 | 操作 | `恢复所选`（Secondary，Primary 仅当有勾选时）/ `永久删除`（Danger-Subtle）/ `清理过期` / `导出清单` |
| 4 | 脚注 | 隔离区目录路径（mono）+「过期条目不会自动删除」 |

- 已恢复的行：文字 `text.secondary`，复选框 disabled，状态徽章 `已恢复`。
- 剩余天数 ≤ 3 天 → 数字用 `warning.fg`。
- `恢复` 确认对话框必须显示**完整原路径**。
- `永久删除` / `清空隔离区` 需输入确认文字。

| # | 区块 | 规格 |
|---|---|---|
| 1 | 分段切换 | `扫描记录` / `操作日志` |

## 8. 设置 Settings

布局：`200px 分区导航 + 内容`，gap 24。分区导航 sticky。

| 分区 | 设置项 | 控件 |
|---|---|---|
| **常规** | 默认清理动作 / 清理前创建系统还原点 / 启动时检查更新 | Select / Switch / Switch |
| **扫描** | 最大扫描层级 / 包含隐藏目录 / 软件判定阈值 / 默认扫描盘符 | Select / Switch / Select / TagList |
| **保护与白名单** | 允许处理高风险条目 / 系统关键路径硬保护（只读徽章）/ 排除路径 / 保留关键词 | Switch / Badge / TagList / TagList |
| **隔离区** | 隔离区目录 / 保留天数 / 当前占用 | Input+浏览 / Select(7/15/30) / 跳转按钮 |
| **外观** | 主题模式（跟随系统/浅色/深色）/ 减少动画 / 界面字体 | 三选一卡片 / Switch / Select |
| **高级** | 单目录文件统计上限 / 扫描并发度 / 日志目录 / 恢复默认设置 | Input / Select / 按钮 / Danger-Subtle |

- 每个设置项：名称 `body` 600 + 说明 `caption` `text.secondary`（最大宽 560）+ 右侧控件区 220px。
- 行分隔 1px `border.subtle`，padding 16/0。
- TagList 项可单独删除；末尾虚线「添加」。
- **无「保存」按钮**：修改即时生效并持久化（与现状 `ISettingsService.SaveAsync` 一致）。
