# 图标系统（Icon System）

## 1. 设计规格

| 项 | 规格 |
|---|---|
| 栅格 | **24 × 24**，内容安全区 2px（可见内容落在 2–22） |
| 风格 | 线性（outline），**不使用填充图标**（品牌 Logo 除外） |
| 描边宽度 | **1.75**（20px 下渲染为 1.46px；16px 下强制 2.0 以保证可见） |
| 端点 / 连接 | `stroke-linecap: round` + `stroke-linejoin: round` |
| 填充 | `fill: none`（除 `gc-brand`） |
| 颜色 | `currentColor` —— 永远继承文字颜色，禁止硬编码 |
| 圆角 | 外框类图标（rect）圆角 **2**（非 8，避免 Web 感） |

## 2. 尺寸表

| 尺寸 | 用途 | 描边 |
|---|---|---|
| **16** | 徽章内图标、表格行内状态、密集区域 | 2.0 |
| **20** | 侧栏导航、按钮内图标、工具栏 | 1.75 |
| **24** | 分区标题、对话框标题、列表行首 | 1.75 |
| **32** | 空状态（Empty State） | 1.6 |
| **48** | 全页空状态 / 错误状态插画 | 1.4 |

## 3. 使用规则

1. **禁止 emoji**。`Evidence.IconText`（`✓` / `⚠`）在 UI 0.2 中必须替换为 `gc-check` / `gc-alert-triangle`。
2. **禁止使用 Segoe MDL2 Assets / Segoe Fluent Icons** —— 与自定义线性图标混用会风格撕裂。
3. 图标与文字的间距固定 **8px**（16px 图标用 6px）。
4. 图标颜色默认继承 `text.secondary`；**仅当图标承载语义时**才用语义色：
   - 保护 / 成功 → `success.fg`
   - 需复核 / 警告 → `warning.fg`
   - 高风险 / 永久删除 → `danger.fg`
   - 其余一律中性。
5. 图标**永不单独承载信息**，必须配文字或 Tooltip（无障碍要求）。

## 5. 空状态插画规范

不使用卡通插画。空状态 = **48px 线性图标（中性色）+ 一句说明 + 一个主操作**。

| 场景 | 图标 | 文案示例 |
|---|---|---|
| 尚无扫描结果 | `gc-scan` | 还没有扫描过。开始第一次扫描，看看 Windows 忘记了什么。 |
| 筛选后无结果 | `gc-filter` | 当前筛选条件下没有条目。试试切换筛选或清空搜索。 |
| 隔离区为空 | `gc-quarantine` | 隔离区是空的。被隔离的目录会暂时存放在这里，可随时恢复。 |
| 无扫描记录 | `gc-history` | 还没有扫描记录。 |
| 权限不足 | `gc-lock` | 未以管理员身份运行，部分系统信息读取不完整。 |
| 扫描失败 | `gc-alert-circle` | 扫描未能完成。 |
| 搜索无匹配 | `gc-search` | 没有匹配的条目。 |
