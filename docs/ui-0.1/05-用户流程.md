# Phase 5 — 用户流程（User Flow）

## 流程 1（主流程，必须完整）：一次完整的残留处理

```mermaid
flowchart TD
    A["打开 GhostCleaner"] --> B["概览 Dashboard"]
    B -->|"主 CTA：开始扫描"| C["残留扫描 · 配置"]
    C --> C1{"选择范围"}
    C1 -->|"盘符 / 自定义目录"| C2["确认扫描选项"]
    C2 -->|"开始扫描"| D["扫描准备<br/>建立系统关联索引"]

    D --> E["扫描中<br/>阶段：枚举候选 → 逐个度量 → 分析判定"]
    E --> E1{"用户操作"}
    E1 -->|"暂停"| E2["已暂停<br/>可继续 / 取消"]
    E2 --> E
    E1 -->|"取消"| B
    E1 -->|"完成"| F["扫描完成<br/>已检查 N 目录 / 发现 N 项 / 高可信 N / 需复核 N"]

    F -->|"主 CTA：查看扫描结果"| G["扫描结果 · 列表"]
    F -->|"重新扫描"| C

    G --> H{"筛选"}
    H -->|"全部 / 高可信度 / 需要复核 / 受保护"| I["选中某一条目"]
    I --> J["右侧详情面板"]

    J --> J1["看检测依据<br/>正向证据 + 权重"]
    J --> J2["看保护信号<br/>负向证据"]
    J --> J3["看清理风险与推荐操作"]
    J --> J4{"确认安全性"}
    J4 -->|"不确定"| K["打开文件夹 / 运行卸载程序"]
    K --> J
    J4 -->|"确定是残留"| L["勾选"]
    J4 -->|"不是残留 / 重要"| M["加入白名单"]
    J4 -->|"不动"| I

    L --> N["底部操作栏<br/>已选 N 项 · 共 X GB"]
    N -->|"移入隔离区（默认）"| O["二次确认对话框"]
    O -->|"确认"| P["执行：创建还原点 → 移动 → 写日志"]
    P --> Q["清理完成<br/>N 项已隔离 · 可在隔离区恢复"]
    Q --> R["隔离区"]
    Q --> B
```

### 流程 1 的关键设计约束

| 节点 | 约束 |
|---|---|
| 扫描准备 → 扫描中 | 必须让用户知道「正在建立系统关联索引」，因为这一步决定了结果可不可信 |
| 扫描中 | 必须同时显示：当前路径、百分比、**已检查目录数**、**已发现候选数**、已用时间；必须能暂停和取消 |
| 扫描完成 | 必须明确「高可信度 N」与「需要复核 N」两个数字分开显示，不得合并成一个总数 |
| 结果列表 | 默认**全部未勾选** |
| 详情面板 | 正向证据与保护信号**必须分区展示**，不能混在一个列表里 |
| 二次确认 | 必须显示：条目数、总大小、动作后果（可恢复 / 不可恢复） |
| 清理完成 | 必须告知「可在隔离区恢复」，并给出直达入口 |

## 流程 2：从隔离区恢复

```mermaid
flowchart TD
    A["隔离区"] --> B["条目列表<br/>项目 / 原路径 / 隔离时间 / 大小 / 状态 / 剩余天数"]
    B --> C["选中条目"]
    C --> D{"操作"}
    D -->|"恢复"| E["确认：将移回原路径<br/>D:\\Program Files\\XXX"]
    E -->|"确认"| F["执行恢复"]
    F -->|"成功"| G["状态 → 已恢复<br/>Toast：已恢复到原路径"]
    F -->|"失败（原路径已存在）"| H["错误：原路径已存在同名目录<br/>提供：打开原位置 / 取消"]
    D -->|"打开位置"| I["Explorer 打开隔离目录"]
```

| 节点 | 约束 |
|---|---|
| 恢复确认 | 必须显示**完整原路径**，用户要能确认会回到哪里 |
| 恢复失败 | 必须说明失败原因，并提供「打开原位置」让用户自己处理 |
| 恢复成功 | 条目不立即消失，状态变为「已恢复」，可筛选隐藏 |

## 流程 3：永久删除（最高危）

```mermaid
flowchart TD
    A["隔离区 / 扫描结果"] --> B["点击 永久删除"]
    B --> C{"是否有高风险条目"}
    C -->|"有 且 未开启 AllowHighRiskClean"| D["自动跳过并提示"]
    C -->|"无 / 已授权"| E["危险确认对话框"]
    E --> F["必须手动输入：永久删除"]
    F -->|"输入不匹配"| G["按钮禁用（不可用灰显）"]
    G --> F
    F -->|"输入匹配"| H["按钮启用"]
    H -->|"点击"| I["执行永久删除"]
    I --> J["完成：N 项已永久删除 · 不可恢复"]
```

| 节点 | 约束 |
|---|---|
| 确认文字 | 必须与 `CleanupService.PermanentDeleteConfirmText` 一致（现状：*永久删除*） |
| 按钮状态 | 输入不匹配时**禁用**，不是点击后报错 |
| 配色 | 整个对话框使用 Danger 色系，但**只在按钮与图标上**，背景保持中性 |
| 文案 | 必须明确「不可恢复」 |

## 流程 4：结果详情 → 打开 / 白名单

```mermaid
flowchart TD
    A["扫描结果"] --> B["选中条目 → 详情面板"]
    B --> C{"用户动作"}
    C -->|"打开文件夹"| D["Explorer 打开该目录"]
    C -->|"运行卸载程序"| E["启动 unins000.exe 等"]
    C -->|"复制路径"| F["写入剪贴板 · Toast 提示"]
    C -->|"加入白名单"| G["写入 ExcludedPaths"]
    G --> H["条目状态 → 已排除<br/>取消勾选 · 永不参与删除"]
    C -->|"导出报告"| I["JSON / CSV"]
```

| 节点 | 约束 |
|---|---|
| 加入白名单 | 必须立即在列表上反馈（状态徽章变化 + 取消勾选），并且提示「可在设置 → 保护与白名单 中移除」 |
| 打开文件夹 | 若目录已不存在，按钮禁用并说明原因 |

## 流程 5（补充）：首次启动 / 权限不足

```mermaid
flowchart TD
    A["首次打开"] --> B{"是否管理员"}
    B -->|"是"| C["正常进入概览"]
    B -->|"否"| D["概览顶部显示 · 权限提示条<br/>（Warning，非阻断）"]
    D --> E["用户仍可扫描"]
    E --> F["扫描完成页显示 警告：<br/>部分关联来源未检查 · 结果偏保守"]
    F --> G["结果条目风险自动升为 高 · 需人工复核"]
```

> **设计原则：权限不足不阻断，但必须持续可见地告知。** 这比弹一个"请以管理员身份重启"的模态框更有用。

## 6. 状态机：扫描流程

```mermaid
stateDiagram-v2
    [*] --> Idle
    Idle --> Preparing: 开始扫描
    Preparing --> BuildingIndex: 建立关联索引
    BuildingIndex --> Enumerating: 索引完成（可能部分失败）
    Enumerating --> Inspecting: 枚举候选
    Inspecting --> Analyzing: 逐个度量
    Analyzing --> Completed: 判定完成
    Enumerating --> Paused: 暂停
    Inspecting --> Paused: 暂停
    Paused --> Enumerating: 继续
    Paused --> Cancelled: 取消
    Enumerating --> Cancelled: 取消
    Inspecting --> Cancelled: 取消
    Enumerating --> Failed: 严重错误
    Completed --> Idle: 查看结果 / 重新扫描
    Cancelled --> Idle
    Failed --> Idle
```

> `Paused` 与 `BuildingIndex / Enumerating / Inspecting / Analyzing` 阶段需要 Core 提供（`UDR-01` / `UDR-05`）。UI 0.1 设计已完成，Core 未就绪前 UI 0.2 可先降级为「准备 → 扫描中 → 完成」三态。
