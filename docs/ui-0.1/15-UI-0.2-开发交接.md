### 5.2 关键规则

1. **颜色一律 `DynamicResource`**，间距/圆角/字号用 `StaticResource`。
2. 主题切换 = 替换 `MergedDictionaries` 中 `Theme.Light.xaml` / `Theme.Dark.xaml`。
3. **禁止在 XAML 中出现任何十六进制颜色或 `White` / `Black` 字面量。**
4. 数字文本一律加 `Typography.NumeralAlignment="Tabular"`（或全局 Style）。
5. 字体：`FontFamily="Segoe UI Variable Display, Segoe UI, Microsoft YaHei UI"`。

### 5.3 主题服务

```csharp
public enum ThemeMode { System, Light, Dark }

public interface IThemeService
{
    ThemeMode Mode { get; }
    ThemeMode EffectiveMode { get; }          // System 解析后的实际值
    void Apply(ThemeMode mode);
    event EventHandler? Changed;              // 跟随系统时，系统主题变化触发
}
```

- 跟随系统：监听 `Microsoft.Win32.SystemEvents.UserPreferenceChanged`，或读
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`。
- 持久化到 `AppSettings.ThemeMode`（`UDR-07`）。

`assets/icons/gc-icons.svg` 中每个 `<symbol>` 内部的 `<path d="...">` 直接转成 WPF：

```xml
<!-- Icons/IconSet.xaml -->
<Geometry x:Key="Icon.Scan">M3 8V6a2 2 0 0 1 2-2h2 M16 4h2a2 2 0 0 1 2 2v2 ...</Geometry>
```

```xml
<!-- 使用 -->
<Path Data="{StaticResource Icon.Scan}" Width="20" Height="20" Stretch="Uniform"
      Stroke="{DynamicResource Brush.Text.Secondary}" StrokeThickness="1.75"
      StrokeStartLineCap="Round" StrokeEndLineCap="Round" StrokeLineJoin="Round" />
```

| 项 | 值 |
|---|---|
| viewBox | 24 × 24（`gc-brand` 为 48 × 48） |

## 7. UI Data Requirements（交给 Core 开发线）

> 按方案第十一节：UI 不修改 Core，只登记需求。UI 0.2 用 Mock / 降级方案实现。

| ID | 需求 | 优先级 | 建议接口 | 缺失时的 UI 降级 |
|---|---|---|---|---|
| `UDR-01` | 扫描暂停 / 恢复 | **P0** | `Task PauseAsync() / ResumeAsync()` 或 `ScanController` | 隐藏「暂停」按钮，步骤条退化为单阶段 |
| `UDR-02` | 扫描结果持久化 + 扫描记录 | **P0** | `IScanHistoryService { Task<IReadOnlyList<ScanRecord>> ListAsync(); Task<ScanRecord> SaveAsync(...); Task<ScanRecord?> GetAsync(id); }`<br>`ScanRecord { Id, StartedAt, FinishedAt, RootPaths, Options, DurationMs, ScannedDirectories, Items (snapshot), Summary }` | 扫描记录页只读操作日志；「查看结果」隐藏；概览「上次扫描」从日志派生 |
| `UDR-03` | 进度真实总量 | **P0** | `ScanProgress.TotalDirectories`（预估或已发现总数） | 扫描中改用不确定进度条，只显示「已检查 N 个目录」 |
| `UDR-04` | 已用时间 / 剩余预估 | P1 | `ScanProgress.Elapsed`、`EstimatedRemaining` | 只显示已用时间（UI 本地计时） |
| `UDR-05` | 当前扫描阶段 | P1 | `ScanProgress.Phase : ScanPhase { Preparing, BuildingIndex, Enumerating, Inspecting, Analyzing, Completed }` | 步骤条隐藏，只显示「正在扫描」 |
| `UDR-06` | 跳过 / 不可读路径统计 | P1 | `ScanProgress.SkippedCount`、`SkippedReasons` | 完成页不显示该项 |
| `UDR-07` | 主题偏好持久化 | P1 | `AppSettings.ThemeMode` | 存到独立 `ui.json` |
| `UDR-08` | 白名单结构化 | P2 | `ExcludedPathEntry { Path, AddedAt, Source, Note }` | 沿用 `List<string>` |
| `UDR-09` | 证据来源健康度透出 | P1 | `ScanProgress.SourceHealth : IReadOnlyList<AssociationSourceHealth>` | 完成页只显示条目级 `Warnings` |
| `UDR-10` | 目录被占用检测 | P2 | `OrphanItem.IsLocked`、`LockingProcesses` | 不提示 |
| `UDR-11` | 命名空间 / 显示名统一为 GhostCleaner | **P1** | `WinCleaner.*` → `GhostCleaner.*`；窗口标题、侧栏、日志文案 | UI 层先改显示名 |

### 建议的 Core 接口补充（供参考，最终由 Core 决定）

```csharp
public sealed class ScanRecord
{
    public string Id { get; init; } = Guid.NewGuid().ToString("N");

    public int ScannedDirectories { get; init; }

    public bool Completed { get; init; }
    public IReadOnlyList<OrphanItem> Items { get; init; } = Array.Empty<OrphanItem>();
```

## 9. 无障碍交接

| 项 | 要求 | WPF 实现 |
|---|---|---|
| 焦点可见 | 2px `accent.500` + 2px 偏移 | `FocusVisualStyle` 或 `KeyboardNavigation.ShowFocusVisual` |
| 键盘可达 | 全部交互可 Tab | 默认；注意自定义控件需 `IsTabStop="True"` |
| 列表键盘操作 | ↑↓ 移动 / Space 勾选 / Ctrl+A 全选 | `KeyDown` 处理 |
| 对比度 | 正文 ≥ 4.5:1 | 见 `07` §17（已验证） |
| 色彩依赖 | 状态必须同时有图标 + 文字 | Badge 必带图标 |
| 最小点击目标 | 32×32 | IconButton `sm` 为 28，需保证父容器 padding 补足 |
| 自动化 | 关键控件设 `AutomationProperties.Name` | 结果项、徽章、进度条 |
