它不做什么
不做"一键清理"
没有体检分数，没有一键加速，不会替你做决定。
不输出"删除"建议
扫描器只输出"建议人工确认后隔离"，永远不输出"删除"。
不隐藏不确定性
关联来源读取失败、扫描不完整、判定不可靠都会明确告诉你。
安全设计
默认不删除任何东西
扫描只做检测，结果条目默认全部未勾选。
默认动作是可恢复的隔离
目录被移动到隔离区而非删除，可随时恢复到原始路径。
永久删除需要输入确认文字
必须手动输入「永久删除」，按钮才允许执行。
系统关键路径硬保护
Windows / System32 / ProgramData / AppData / Users 等路径在任何入口都会被拒绝。
多源判定而不是只看注册表
9 类来源全部查不到引用，才会被判定为疑似残留。
白名单优先
排除路径与保留关键词命中的目录永不参与删除。
两个不同的问题
疑似残留度
我们有多大把握认为它是残留？与"能不能删"无关。
92%
清理风险
如果清理它，可能有多危险？残留度高 ≠ 可以清理。
高 检测到用户配置与近期修改
