# 组件规范 v0.1（Components）

> 每个组件列出：**尺寸 / 变体 / 全部状态 / 使用的 token**。
> UI 0.2 按此表建 `ControlTemplate`。可运行参考：`prototype/css/components.css`。

## 通用状态定义（所有交互组件共有）

| 状态 | 视觉规则 |
|---|---|
| `Rest` | 默认 token |
| `Hover` | 背景 / 边框升一级（`dur.fast`） |
| `Pressed` | 背景再降一级；**无位移**（不做"按压下沉"） |
| `Focus` | 2px `accent.500` 外描边 + 2px 偏移（`bw.strong`）。**键盘 Tab 才出现，鼠标点击不出现** |
| `Disabled` | 背景 `n.100`，文字 `text.disabled`，`Opacity = 1`（不用 Opacity 降透明度，避免文字发虚） |
| `Loading` | 内容替换为 16px 旋转指示器 + 保留原文字宽度，禁止按钮跳动 |

## 1. Button

### 尺寸

| 变体 | 高度 | 左右 padding | 字号 | 圆角 |
|---|---|---|---|---|
| `sm` | 28 | 12 | 13 | 6 |
| `md`（默认） | 32 | 16 | 14 | 6 |
| `lg`（主 CTA） | 40 | 24 | 14 / 600 | 6 |

### 变体与状态

| 变体 | Rest | Hover | Pressed | Disabled |
|---|---|---|---|---|
| **Primary** | bg `accent.500`, fg `#FFF` | bg `accent.600` | bg `accent.700` | bg `n.100`, fg `text.disabled` |
| **Secondary**（默认） | bg `bg.surface`, fg `text.primary`, 1px `border.default` | bg `bg.hover`, border `border.strong` | bg `n.200` | bg `n.100`, fg `text.disabled`, border `border.subtle` |
| **Subtle / Ghost** | bg transparent, fg `text.secondary` | bg `bg.hover`, fg `text.primary` | bg `n.200` | fg `text.disabled` |
| **Danger** | bg `danger.default`, fg `#FFF` | bg `danger.hover` | bg `danger.hover` + 内描边 | bg `n.100`, fg `text.disabled` |
| **Danger-Subtle** | bg transparent, fg `danger.fg`, border `danger.border` | bg `danger.bg` | bg `danger.border` | fg `text.disabled`, border `border.subtle` |

- 最小宽度 **72px**（`sm` 为 56px）。
- 图标 + 文字：图标 16px，间距 8px，图标在前。
- 一个视图内 **Primary 只能有 1 个**。

## 2. IconButton

- 尺寸：`sm` 28×28 / `md` 32×32，图标 16px / 20px，圆角 6。
- 变体同 Button 的 Secondary / Subtle / Danger-Subtle。
- **必须带 Tooltip**。

## 3. Card

```
bg.surface · border 1px border.subtle · radius 8 · padding 20 · 无阴影
```

- 可选 `Header`（`h3` 标题 + 右侧操作区）+ `Body` + `Footer`（1px `border.subtle` 上边线，padding 12/20）。
- **禁止卡片内嵌卡片出现阴影。**

## 4. Section（分区）

```
分组标题：overline 11/600 +0.06em, text.tertiary, margin-bottom 12
```
- 分区之间用 **1px `border.subtle` 分隔线** 或 **24px 间距**，二选一，不叠加。

## 5. Badge / StatusPill

- 高度 20，padding 0/8，圆角 999，字号 11/600，图标 12。
- 配色 = 语义色 `*.bg` + `*.fg` + `1px *.border`。
- 类型：待处理 / 已保护 / 已排除 / 需复核 / 扫描不完整 / 已隔离 / 已恢复 / 已清除 / 异常。
- 见 `07` §9。

## 6. RiskBadge（清理风险）

- 同 Badge 尺寸，图标 12（低 `shield-check` / 中 `shield-alert` / 高 `alert-circle`）。
- 文案固定：**低 / 中 / 高**（与 `OrphanItem.RiskText` 一致）。
- 配 Tooltip：`清理风险：{低|中|高}。风险来自 {ProtectionReason / 判定原因}`。

## 7. ConfidenceBar（疑似残留度）+ ConfidenceValue

```
┌────────────────────────────┐
│ ████████████░░░░  92%      │   条形 4px 高 / radius 999 / 底 n.200
└────────────────────────────┘   数字 13/600 tabular，accent.fg
```
- 条形宽度 96px（固定），数字紧跟其后，间距 8。
- 填充色见 `07` §7。**绝不使用绿 / 红。**
- 无障碍：`aria-label="疑似残留度 92%，非常高概率残留"`。
- Tooltip：`疑似残留度回答"我们有多大把握认为它是残留"，不等于清理风险。`

## 8. CheckBox

- 方框 16×16，圆角 4，边框 1px `border.strong`。
- `Unchecked`：bg `bg.surface`
- `Hover`：border `accent.500`
- `Checked`：bg `accent.500`，内 `gc-check` 12px 白色
- `Indeterminate`：bg `accent.500`，内 8×2 白色横条（用于表头全选）
- `Disabled`：bg `n.100`，border `border.subtle`
- 文字 14 / `text.primary`，与框间距 8。

## 9. Switch（Toggle）

- 轨道 36×20，圆角 999；滑块 16×16 圆，`bg.surface` + `elevation.1`。
- `Off`：轨道 `n.300`；`On`：轨道 `accent.500`；`Disabled`：`n.100`。
- 切换 `dur.fast`，滑块位移 16→36。

## 10. Segmented（筛选分段控件）

- 容器 bg `bg.sunken`，圆角 6，padding 2，内项高 28。
- 选中项 bg `bg.surface` + `elevation.1` + `text.primary`（600）。
- 未选中 `text.secondary`；Hover `text.primary`。
- 用于「全部 / 高可信度 / 需要复核 / 受保护」；可带计数 `(7)`。

## 11. TextInput

- 高度 32，padding 0/12，圆角 6，bg `bg.surface`，1px `border.default`，字号 14。
- `Hover` → border `border.strong`；`Focus` → border `accent.500` + 2px 焦点环。
- `Error` → border `danger.default`，下方 12px `danger.fg` 说明，间距 4。
- `ReadOnly` → bg `bg.sunken`，fg `text.secondary`。
- `Placeholder` → `text.tertiary`。

## 12. SearchInput

- 同 TextInput，前置 16px `gc-search`（`text.tertiary`），右侧可出现 16px 清除 `gc-close`（IconButton sm）。

## 13. Select / ComboBox

- 高度 32，padding 0/12，圆角 6，右侧 16px `gc-chevron-down`。
- 下拉面板：`bg.surface` + `elevation.1` + 1px `border.subtle`，圆角 6，项高 32，padding 0/12；Hover `bg.hover`，选中 `bg.active` + `accent.fg`。

## 14. Progress

| 类型 | 规格 |
|---|---|
| Determinate（条形） | 高 6，圆角 999，轨道 `n.200`，填充 `accent.500`，`dur.fast` 过渡 |
| Determinate（环形） | **仅限扫描中页面**，直径 88，轨道宽 6，填充 `accent.500`，中心 20/600 百分比 |
| Indeterminate | 高 2 或 6，填充为 30% 宽滑块，1.4s linear 无限 |

> **禁止巨大百分比圆环**（V8）。扫描中页面的环形直径上限 **88px**，不得超过。

## 15. Table / DataGrid

| 项 | 规格 |
|---|---|
| 行高 | **36**（紧凑）/ 44（默认） |
| 表头 | 高 36，bg `bg.sunken`，11/600 `text.secondary`，下边线 1px `border.default`；**无竖向网格线** |
| 行分隔 | 1px `border.subtle`；**禁止斑马纹**（用分隔线） |
| 行 Hover | `bg.hover` |
| 行 Selected | `bg.active` + 左侧 3px `accent.500` |
| 单元格 padding | 0/16 |
| 数字列 | 右对齐 + tabular |
| 路径列 | `font.mono` 12，`text.secondary`，**中间省略**（保留头尾） |
| 空态 | 见 §22 |

## 16. ResultItem（扫描结果条目）★ 核心组件

```
┌──────────────────────────────────────────────────────────────┐
│ ☐  ExampleApp                          [中] [已保护]         │   行1：h3 名称 + 状态徽章（右）
│    D:\Program Files\ExampleApp                    1.42 GB    │   行2：mono-sm 路径 + 大小（右，tabular）
│    ▓▓▓▓▓▓▓▓▓░░ 92%   未发现卸载项 / 未发现服务 / 731 天未改  │   行3：ConfidenceBar + 依据摘要
└──────────────────────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 高度 | 72（三行）；紧凑模式 56（两行，隐藏依据摘要） |
| padding | 12 / 16 |
| 分隔 | 1px `border.subtle`；**不用卡片包裹**（列表用容器边框，不用逐项卡片） |
| Hover | `bg.hover` |
| Selected（点击选中查看详情） | `bg.active` + 左侧 3px `accent.500` |
| Checked（勾选待处理） | 不改变背景，仅 CheckBox 变 **accent 实心**；与 Selected 独立 |
| Protected / Excluded | 整行 `Opacity = 1`（不降透明），改为：名称 `text.secondary` + CheckBox `disabled` + 状态徽章 |
| 风险徽章 | 右侧，与状态徽章间距 8 |
| 依据摘要 | 最多显示 3 条，用 `·` 分隔，超出显示 `+N` |

**两个视觉通道必须可区分**：`Selected`（蓝色底 + 左指示条）= 正在看；`Checked`（复选框）= 要处理。

## 17. EvidenceItem（证据条目）★ 核心组件

```
┌────────────────────────────────────────────────┐
│ ✓  未发现卸载项                          +25   │   图标 16 + 标题 14/600 + 权重（右，tabular）
│    在 HKLM/HKCU 卸载项中查不到该目录            │   描述 12，text.secondary
└────────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| padding | 8 / 12 |
| 分隔 | 1px `border.subtle` |
| 正向证据 | 图标 `gc-check` 16，`success.default`；权重 `+25`，`success.fg` |
| 负向证据（保护信号） | 图标 `gc-alert-triangle` 16，`warning.default`；权重 `−30`，`warning.fg` |
| 权重数字 | 13/600 tabular，右对齐，最小宽度 40（保证对齐） |
| 分组标题 | 「检测依据（支持"是残留"）」/「保护信号（支持"保留"）」，overline 11/600 |

> **正向与负向必须分区，禁止混排。** 这是 GhostCleaner 的核心价值。

## 18. NavigationItem（侧栏）

- 高度 40，padding 0/12，圆角 6，margin 0/8/2/8。
- 图标 20（`text.secondary`），文字 14，间距 12。
- `Rest`：transparent，`text.secondary`
- `Hover`：`bg.hover`，`text.primary`
- `Active`：`bg.active`，`text.primary` 600，图标 `accent.fg`，**左侧 3px `accent.500` 指示条**（圆角 999，高 16，居中）
- `Focus`：2px 焦点环

## 19. Toolbar

- 高度 48，1px `border.subtle` 下边线，内部元素间距 8，右侧操作区靠右。
- 主操作在**左**，破坏性操作在**右**。

## 20. ActionBar（底部操作栏）★

- 高度 64，bg `bg.surface`，上边线 1px `border.default`，`elevation.1`（因为是浮在内容上的）。
- 左侧：勾选摘要 `已选 {N} 项 · 共 {X}`（14/600，数字 tabular）。
- 中间：次要动作（导出、全不选、仅选低风险）。
- 右侧：主动作 `移入隔离区`（Primary）+ `永久删除`（Danger-Subtle）。
- **无勾选时不显示**（或整体禁用并显示提示）。

## 21. Dialog

| 项 | 规格 |
|---|---|
| 宽度 | 480（标准）/ 560（含列表）/ 400（简单确认） |
| padding | 24 |
| 圆角 | 12 |
| 阴影 | `elevation.2` |
| 遮罩 | `bg.scrim` + 淡入 `dur.fast` |
| 入场 | 对话框 `opacity 0→1` + `scale .96→1`，`dur.slow` `ease.decelerate` |
| 标题 | `h2` 16/600，左侧可配 20px 图标 |
| 正文 | 14/20 `text.secondary`，最大宽度 432 |
| 按钮区 | 右下，间距 8，顺序：`取消`（Secondary）→ `确认`（Primary/Danger） |
| 关闭 | 右上角 IconButton `gc-close`；Esc 关闭；点击遮罩关闭（**危险对话框禁用此行为**） |

### 危险确认对话框（Danger Dialog）

- 标题图标 `gc-alert-triangle` 20，`danger.fg`。
- 需要输入确认文字时：TextInput + 提示「输入 `永久删除` 以继续」；**输入不匹配 → 主按钮 Disabled**。
- 遮罩点击**不关闭**，Esc **不关闭**（必须显式选择）。

## 22. EmptyState

```
         [48px 图标，text.tertiary]
      主文案（16/600, text.primary）
   说明文案（13, text.secondary, 最大宽 360）
        [Primary Button]（可选）
```
- 垂直居中于内容区，最小高度 240。
- 图标 48px，`text.tertiary`（不用彩色）。

## 23. Toast

| 项 | 规格 |
|---|---|
| 位置 | 右下角，距边 24 |
| 尺寸 | 最小宽 320，最大 420，padding 12/16，圆角 8 |
| 样式 | `bg.surface` + `elevation.1` + 1px `border.subtle` |
| 图标 | 16（success `circle-check` / warning `alert-triangle` / danger `alert-circle` / info `info`） |
| 文案 | 13/18，最多 2 行 |
| 动作 | 最多 1 个文字按钮（右） |
| 时长 | 4000ms（含动作 6000ms）；Danger 需手动关闭 |
| 入场 | 右移 + 淡入 `dur.normal` `ease.decelerate` |
| 最多同时 | 3 条（超出堆叠替换最旧） |

## 24. Tooltip

- bg `n.900`（Dark `n.800`），fg `#FFF`（Dark `text.primary`），padding 6/10，圆角 6，字号 12，`elevation.1`。
- 延迟 400ms 出现，`dur.fast`。
- **永不承载唯一信息**。

## 25. Expander / 折叠分区

- 头部高 40，图标 `gc-chevron-right` 16（展开时旋转 90°，`dur.fast`）。
- 标题 14/600；可选右侧计数。
- 内容 padding 12 0 0 0；展开 / 折叠高度动画 `dur.normal`。

## 26. PathText（路径显示）

- `font.mono` 12/13，`text.secondary`。
- 超长时**中间省略**：`D:\Program Files\…\resources\lang`。
- 配 `gc-copy` IconButton（复制）+ 可选 `gc-folder-open`（打开）。
- **绝不换行**（路径换行会破坏扫描结果列表的扫读性）。

## 27. MetricTile（概览度量块）

```
┌──────────────────┐
│ 上次扫描          │   overline 11/600 text.tertiary
│ 2 天前            │   metric 28/32 600 tabular
│ 2026-10-05 14:22  │   caption 12 text.tertiary（可选副行）
└──────────────────┘
```
- 容器：`bg.surface` + 1px `border.subtle` + radius 8 + padding 16。
- 度量数字 `metric`（28/32/600），tabular。
- 单位与数字之间 4px，单位字号 13 `text.secondary`。

## 28. FilterTabs（结果页筛选）

- 用 Segmented（§10），每项带计数：`高可信度 (3)`。
- 计数用 `text.tertiary`，选中后变 `accent.fg`。

## 组件 → 现有代码迁移对照（UI 0.2 用）

| 组件 | 现状 | UI 0.2 动作 |
|---|---|---|
| Button | `BaseButton` / `PrimaryButton` / `DangerButton` / `WarningButton`（硬编码 `#E5E7EB`） | 重写为 token 驱动，补 Hover/Pressed/Focus/Loading |
| Card | `Card` Style（带 `DropShadowEffect`） | 去掉阴影，改 1px 边框 |
| NavigationItem | `NavItemContainer`（`#374151` / `#2563EB` 硬编码） | 重写，补图标与左指示条 |
| Table | 裸 `DataGrid` | 建完整 DataGrid Style（行高/悬停/选中/空态） |
| ResultItem | 无（DataGrid 行） | **新建** |
| EvidenceItem | 无（`EvidenceText` 字符串） | **新建** |
| ConfidenceBar | 无（只有 `ConfidenceText`） | **新建** |
| RiskBadge | 无（只有 `RiskText`） | **新建** |
| Dialog | `MessageBox` + `ConfirmTextWindow` | 统一为 Dialog 组件 |
| Toast | 无（用 `MessageBox`） | **新建** |
| EmptyState | 无 | **新建** |
| ActionBar | 无（按钮堆在页面顶部） | **新建** |
