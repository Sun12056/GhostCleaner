# 状态设计 v0.1（Empty / Loading / Error / …）

> 方案第二十九节要求：UI 0.1 必须设计完整状态，而不是只设计正常状态。

## 1. 全局状态清单

| 状态 | 出现位置 | 视觉 | 文案基调 |
|---|---|---|---|
| **Empty** | 结果列表 / 隔离区 / 扫描记录 / 白名单 | EmptyState（48px 中性图标 + 标题 + 说明 + 可选按钮） | 说明"为什么是空的"+"下一步能做什么" |
| **Loading** | 页面首帧 / 列表刷新 | 骨架条（`bg.sunken` 圆角 4，1.4s 呼吸）或 16px 环形指示器 | 无文案，或 `正在读取…` |
| **Scanning** | 扫描中页 | 见 `10` §3 | 陈述进行中的动作 |
| **Paused** | 扫描中页 | 进度环去强调 + 文案替换 | `已暂停` |
| **Completed** | 扫描完成页 | `gc-circle-check` 48px success | 结论式 |
| **Partial**（扫描不完整） | 完成页 / 结果页 / 详情面板 | `banner-warning` | **明确说出哪些来源没检查**，以及后果 |
| **Error** | 全局 / 页面级 | `banner-danger` 或 ErrorState | 说明失败原因 + 可执行的下一步 |
| **Permission Denied** | 概览顶部 / 扫描页 / 完成页 | `banner-warning`（**非阻断**） | 说明影响范围，不命令用户重启 |
| **Protected** | 结果项 / 详情面板 | `已保护` 徽章 + 复选框禁用 | 说出保护原因 |
| **Excluded** | 结果项 / 详情面板 | `已排除` 徽章 + 复选框禁用 | 说明可在设置中移除 |
| **Success** | Toast / 完成页 | `gc-circle-check` success | 陈述结果 + 可逆性 |
| **Warning** | 多处 | `banner-warning` | 说明风险，不恐吓 |

## 2. Empty State 规格

```
              [48px 图标 · text.tertiary]

           主文案（16/600 · text.primary）

    说明文案（13/18 · text.secondary · 最大宽 360）

              [Primary Button]（可选）
```

容器：`min-height 240`，垂直居中于内容区。图标**不用彩色**（`text.tertiary`）。

### 全量清单

| # | 页面 | 图标 | 主文案 | 说明 | 操作 |
|---|---|---|---|---|---|
| E1 | 概览（首次） | `gc-scan` | 还没有扫描过 | 开始第一次扫描，看看 Windows 忘记了什么。 | 开始扫描 |
| E2 | 结果（筛选后） | `gc-filter` | 当前筛选条件下没有条目 | 试试切换筛选条件，或清空搜索框。 | 清除筛选 |
| E3 | 结果（全部处理完） | `gc-circle-check` | 本次扫描结果已全部处理完毕 | 处理记录可在「扫描记录」中回看。 | 打开扫描记录 |
| E4 | 隔离区 | `gc-quarantine` | 隔离区是空的 | 被隔离的目录会暂时存放在这里，可随时恢复。 | — |
| E5 | 扫描记录 | `gc-history` | 还没有扫描记录 | 完成一次扫描后，记录会出现在这里。 | 开始扫描 |
| E6 | 设置 · 排除路径 | `gc-bookmark` | 还没有添加排除路径 | 加入后，这些路径及其子目录永不参与删除。 | 添加路径 |
| E7 | 设置 · 保留关键词 | `gc-bookmark` | 还没有添加保留关键词 | 路径任意层级包含关键词即被排除。 | 添加关键词 |
| E8 | 搜索无结果 | `gc-search` | 没有匹配的条目 | 试试换个关键词，或清空搜索框。 | 清空搜索 |
| E9 | 详情面板（未选择） | `gc-file-text` | 选择一个条目 | 点击左侧任意条目，查看它的检测依据、保护信号与推荐操作。 | — |

## 3. Loading State 规格

| 场景 | 形式 | 说明 |
|---|---|---|
| 页面首次加载 | 内容区骨架屏（3~5 条 `bg.sunken` 圆角条，1.4s 呼吸） | 不用全屏 spinner |
| 列表刷新 / 隔离区读取 | 原位置 16px 环形指示器 + `正在读取…` | 保留列表结构 |
| 按钮执行中 | 按钮内 16px 环形 + 文字保留 | **按钮宽度不变** |
| 扫描中 | 专用页面（见 `10` §3） | 不复用通用 Loading |
| 骨架动画 | `opacity 1 → .55 → 1`，1.4s `ease-standard` 无限 | 尊重 `prefers-reduced-motion` |

## 4. Error State 规格

### 4.1 页面级错误（ErrorState）

```
         [48px gc-circle-x · danger.fg]

        操作未能完成

   {具体失败原因，例如：无法写入隔离区目录 E:\CleanerQuarantine}

        [重试]  [查看日志]
```

- 标题 16/600；说明 13/18 `text.secondary`；按钮最多 2 个。
- **必须给出具体原因**（异常 Message），不能只写"出错了"。

### 4.2 行内错误（Inline Error）

- 输入类：`input.error` + 下方 `danger.fg` 说明（12px）。
- 操作类：Toast `danger` +「查看日志」动作。

### 4.3 不阻断错误（Toast）

用于：隔离区读取失败、导出失败、打开文件夹失败、复制失败。
Toast `danger`，**不自动消失**（4000ms → 改为需手动关闭）。

### 4.4 全量错误文案

| 场景 | 文案 |
|---|---|
| 扫描失败 | 扫描未能完成：{reason}。已完成的候选不会写入结果。 |
| 隔离区不可用 | 无法访问隔离区目录 {path}：{reason}。请检查磁盘是否可写，或在设置中更换目录。 |
| 恢复失败 | 恢复失败：原路径已存在同名目录 {path}。请先处理原位置，再重试。 |
| 导出失败 | 导出失败：{reason}。请确认目标路径可写。 |
| 卸载程序无法启动 | 无法启动卸载程序：{reason}。该目录可能已损坏。 |
| 目录已不存在 | 该目录已不存在，可能已被移动或删除。 |

## 5. Permission Denied（权限不足）★ 特别处理

**设计原则：不阻断、不恐吓、持续可见。**

| 位置 | 形式 | 文案 |
|---|---|---|
| 侧栏底部 | 图标 `gc-alert-triangle`（warning）+ `非管理员` | — |
| 概览顶部 | `banner-warning` | 未以管理员身份运行 · 注册表卸载项、服务、计划任务等来源可能读取不完整。判定会偏保守：受影响的结果会被标记为高风险并要求人工复核。 |
| 扫描页（点开始扫描时） | `banner-warning`（**不是模态框**） | 同上，简短版 |
| 扫描完成页 | `banner-warning` | N 个关联来源未完成检查：{来源列表}。相关条目已标记为高风险并要求人工复核。 |
| 结果条目 | 风险徽章 `高` + 警告徽章 | 详情面板警告区说明 |

> **明确禁止**：弹出「请以管理员身份重启程序」的模态框并阻断使用。
> 理由：非管理员下 GhostCleaner 仍然有用（判定偏保守即可），阻断等于让工具不可用。

## 6. Protected / Excluded 状态

| 状态 | 触发（Core 字段） | 徽章 | 交互影响 |
|---|---|---|---|
| 已保护 | `IsProtected = true` | `已保护` + `gc-shield-check`（success） | 复选框禁用；详情显示 `ProtectionReason`；推荐操作降为 `Keep` / `HighRiskReview` |
| 已排除 | `IsExcluded = true` | `已排除` + `gc-eye-off`（neutral） | 复选框禁用；不参与任何清理；详情提示可在设置移除 |
| 系统目录 | 路径命中关键路径 | `已保护` + `gc-lock` | 硬保护，任何入口拒绝 |
| 用户数据 | `HasUserData = true` | 无独立徽章，计入保护信号 | 降低推荐等级 |
| 便携软件 | `DirectoryCategory = PortableSoftware` | 计入保护信号 | 降低推荐等级 |
| 正在运行 | `IsRunning = true` | 计入保护信号（负向证据） | 降低推荐等级 |
| 游戏目录 | `DirectoryCategory = GameDirectory` | 计入保护信号 | 降低推荐等级 |
| 开发项目 | `DirectoryCategory = DevelopmentProject` | 计入保护信号 | 降低推荐等级 |

> 方案第二十八节要求「这些情况应该降低自动清理推荐等级」—— Core 已通过负向证据实现，UI 只负责**如实展示**。

## 7. Partial（扫描不完整）★ 关键状态

当 `AssociationSourceHealth` 中存在失败来源，或任一 `OrphanItem.Warnings` 非空时：

| 位置 | 表现 |
|---|---|
| 扫描完成页 | `banner-warning`：「N 个关联来源未完成检查：{来源}。相关条目已标记为高风险并要求人工复核。」 |
| 结果项 | `需注意` 徽章（`gc-alert-triangle`） |
| 详情面板 | 警告区逐条列出 `Warnings` |
| 结果页顶部 | 摘要文本追加「其中 N 项判定可靠性下降」 |

**必须说明后果**：不是"有些东西没扫到"，而是"因为没扫到，所以判定更保守/更不可信"。

## 8. Success 状态

| 场景 | 形式 | 文案 | 时长 |
|---|---|---|---|
| 移入隔离区 | Toast success + 动作 | N 项已移入隔离区 · 可在隔离区恢复 / [查看隔离区] | 6s |
| 恢复 | Toast success | N 项已恢复到原始路径 | 4s |
| 永久删除 | Toast **danger** | N 项已永久删除 · 不可恢复 | 手动关闭 |
| 加入白名单 | Toast success | 已加入白名单，该目录不会再参与删除 | 4s |
| 导出 | Toast success | 报告已导出 | 4s |
| 创建还原点 | Toast info | 已创建系统还原点 | 4s |
| 复制路径 | Toast success | 路径已复制到剪贴板 | 2s |

> **永久删除的"成功"Toast 使用 danger 色**，因为它不可逆。这是 Danger 色唯一允许的"成功"用法，且必须写「不可恢复」。

---

## 9. 状态优先级（同时满足多条时的展示顺序）

```
Error > Permission Denied > Partial(Warning) > Empty > Loading > Normal
```

例外：
- `Protected` / `Excluded` 是**条目级**状态，与页面级状态并存（不参与竞争）。
- 扫描中页面不参与优先级竞争 —— 它是独占态。
